隐私政策

最后更新：2026年3月25日

在 GuitarChordFlow，我们保护您的隐私。本隐私政策描述了我们如何处理您的个人信息。

1. 我们不收集任何个人信息

GuitarChordFlow 是一款纯本地应用。我们不要求您创建账户，也不会收集、存储或传输任何个人身份信息（PII）到我们的服务器。

2. 不共享数据

由于我们不收集任何数据，因此不会与第三方共享任何数据。

3. 权限说明

  • 音频输出：应用使用 Web Audio API 在本地生成声音。
  • 保持唤醒：应用可能会请求在练习时保持屏幕常亮。
  • 触觉反馈：应用在某些交互中使用触觉反馈。

这些权限均不涉及个人数据的收集。

4. 儿童隐私

由于我们不收集任何个人信息，GuitarChordFlow 对所有年龄段的用户都是安全的。

5. 联系我们

如果您对本隐私政策有任何疑问，请通过 support@xmin.site 联系我们。
